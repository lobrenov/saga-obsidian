# Settings (as built)

Settings → Saga edits `.saga/renderers.yaml` through the config store (`docs/adapter.md`).

## Modules
- `settings/draft.ts` (no Obsidian imports): `Draft` holds the inputs (type key; per renderer in `EDITABLE_IDS` a comma-separated types string, a key per field, blank for the default, and hidden per optional field; per renderer including `document` its pin look as drawn, the built-in defaults under the configured `pin`). `draftOf(config)`, `configOf(draft, base)` (unedited entries and `document` stay as `base` has them), `draftIssues`, `saveText(state, draft)` (`buildConfigText` over the file as read; refused with the issues for an invalid config), `isDirty(draft, base)`, `rebase(draft, previous, next)` (edited inputs keep their value, the rest take `next`'s).
- `settings/index.ts`: `registerSettings(plugin, config, prefs)` adds the `PluginSettingTab`, built with `Setting`.
- `settings/pinPreview.ts`: `drawPinPreview`, the pin defaults row's preview, drawn as the map draws a pin (`map/pinStyles.ts`).

## Behaviour
- Rows: Maps (Pin labels: Always or On hover, in the plugin's `data.json`); Icons (Icon look: Renderer, then one option per map note; in `data.json`, `docs/links.md`); File rendering (Render icons with wikilinks?, Render character titles with wikilinks?; in `data.json`, `docs/links.md`; Render a header on untyped notes? (`documentCard`, default on), in `data.json`, `docs/header.md`); File explorer (Render file icons?, Render icons for untyped files? disabled while it is off; in `data.json`, `docs/explorer.md`); Renderers: type key, then one card per renderer, a `<details>` in a heading-less `setting-group` styled by Obsidian's grouped settings (summary: name, its types as the description and a chevron that turns when open; open cards stay open across re-renders) with Types and one row per field: its key input (the default key as placeholder) and, for an optional field, a Show in the header toggle (off adds it to the renderer's `hidden`, in field order, and disables the key input; rows without a toggle keep its space so the inputs line up); Document is a last card without a chevron, as the fallback. Pin defaults: one row per renderer with a pin preview, Shape and Colour dropdowns, an Icon button (`IconPicker`) and Reset while it differs from the built-in look, saved as the renderer's `pin` with only the keys that differ; the rows share grid columns (`subgrid`, the control's children laid out directly) so each control lines up across rows, and under 30rem the name sits above the controls. An unreadable renderer entry shows its issue and disables its inputs.
- Issues of the saved config show inline and update as the draft changes.
- Edits save on their own 600 ms after the last change (and when the tab closes): `saveText`'s text through `writeConfig`; a refused config shows its issues and writes nothing; a write error shows in the issues area and as a Notice. `applyConfigToYaml` keeps comments, unknown keys, `templates` and key order; an edited value is replaced with its inline comment.
- The tab subscribes while shown. The tab's own save leaves the inputs (and focus) as they are. Another config change rebases the draft; with unsaved edits it shows "renderers.yaml changed on disk; your edits are kept and saved over the new text."
